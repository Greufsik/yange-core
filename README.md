# Yange Core

Современная высокопроизводительная панель для мониторинга сетевых узлов, управления маршрутизацией и прокси-соединениями на базе ядра **Yange**.

---

## ⚡ Особенности

* **Централизованное управление:** Единый веб-интерфейс для управления кластером удалённых серверов и сетевых шлюзов.
* **Современный интерфейс:** Спокойный минималистичный интерфейс с адаптацией под любые устройства.
* **Сетевые протоколы:** Встроенная поддержка VLESS, Hysteria2, TUIC и балансировки соединений.
* **Автоматизация:** Автоматический выпуск и продление SSL/TLS-сертификатов Let's Encrypt.
* **Мониторинг:** Отслеживание трафика, системных ресурсов (CPU, RAM) и активности подключений в реальном времени.
* **Лёгкость и производительность:** Нативная работа через системные службы `systemd` с минимальным потреблением оперативной памяти (~100 МБ).

---

## 🚀 Установка

Поддерживаемые операционные системы: **Ubuntu 22.04+**, **Debian 12+** (x86_64, aarch64).

### 1. Установка панели управления

Для установки полной панели управления с базой данных и локальным узлом на чистый сервер выполните команду от имени `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/Greufsik/yange-core/main/install.sh | sudo bash
```

Установщик в автоматическом режиме:
1. Загрузит необходимые компоненты панели.
2. Установит и настроит СУБД PostgreSQL.
3. Сконфигурирует системные службы `systemd` и правила сетевого экрана.
4. Выведет секретную ссылку и данные для первого входа администратора.

---

### 2. Подключение удалённого узла (ноды)

Чтобы подключить дополнительный сервер к уже работающей панели:

1. Откройте панель управления, перейдите в раздел **«Ноды»** и нажмите **«+ Нода»**.
2. Введите публичный IP-адрес нового сервера и нажмите **«Добавить»**.
3. Панель выдаст команду с уникальным ключом подключения. Выполните её на сервере ноды от имени `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/Greufsik/yange-core/main/install.sh | sudo bash -s -- --join <ВАШ_КЛЮЧ>
```

Узел автоматически установит защищённый туннель mTLS с вашей панелью управления и появится в списке активных серверов через 15–30 секунд.

---

## 📋 Системные требования

* **Панель управления:** от 1 vCPU, 512 МБ RAM, 5 ГБ диска.
* **Удалённый узел (нода):** от 1 vCPU, 256 МБ RAM, 2 ГБ диска.
